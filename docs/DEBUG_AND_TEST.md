# 调试与验证方案 — FPGA 电话中继 + AI 语音指挥系统

版本：v1.0 ｜ 关联文档：`../docs/INTERFACE_SPEC.md`（接口契约，测试判据以其为准）

> 覆盖范围：FPGA 各模块仿真（DTMF / G.711 / I2S / TDM / UART 桥 / 顶层）、
> 上位机音频链路环回、DTMF 误判排查、电话接口电气测试。
> 原则：先仿真后上板，先数字环回后模拟全链路，逐级放行。

## 0. 测试环境与工具

| 类别 | 工具/仪器 | 用途 |
|---|---|---|
| RTL 仿真 | Gowin IDE + ModelSim / iverilog + cocotb | 模块级/顶层仿真 |
| 逻辑分析 | Saleae/逻辑分析仪 ≥ 16 ch、示波器 ≥ 100 MHz | I2S/TDM/PCM/UART 时序 |
| 高压测量 | 高压探头 100×（≥ 200 V 带宽补偿） | −48 V 馈电、90 Vrms 振铃 |
| 电话测试 | 电话分析仪（如 Sundance/Telecom analyzer）或信号发生器 + 仿真线 | 振铃/馈电/DTMF/音频 |
| 上位机 | Python 3 + pyserial + pytest | UART 协议、音频环回自动化 |
| 网络 | sngrep、tcpdump、Wireshark | SIP/RTP（Asterisk 联调） |
| 安规 | 耐压测试仪（AC 0–3 kV）、绝缘电阻表 | 1500 VAC 耐压、绝缘 |

**通用判据**：
- 数字环回必须**逐字节一致**（bit-exact）；
- 音频链路 20 ms 帧周期稳定（160 字节/通道/帧），连续 10 分钟无丢帧（SEQ 连续）；
- 所有寄存器读写与 INTERFACE_SPEC §3 表一致（复位值逐项核对）。

## 1. FPGA 模块级仿真测试方案

### 1.1 DTMF 检测器（`dtmf_detector.v`）

**12 个标准双音逐个激励**（ITU-T Q.23/Q.24 标准组合）：

| 低频 \ 高频 | 1209 Hz | 1336 Hz | 1477 Hz |
|---|---|---|---|
| **697 Hz** | '1' → DIGIT 0x01 | '2' → 0x02 | '3' → 0x03 |
| **770 Hz** | '4' → 0x04 | '5' → 0x05 | '6' → 0x06 |
| **852 Hz** | '7' → 0x07 | '8' → 0x08 | '9' → 0x09 |
| **941 Hz** | '*' → 0x0B | '0' → 0x0A | '#' → 0x0C |

**测试用例表**：

| 用例 | 激励 | 期望结果 | 通过判据 |
|---|---|---|---|
| D-01 ~ D-12 | 12 个标准双音逐个：合成 8 kHz/16 bit 正弦和，幅度 −12 dBm0，时长 120 ms，前/后各 100 ms 静音 | 每音上报 1 个 `DTMF_EVT`（0x20）：`DIGIT` 与表一致，`DUR_MS`≈120 | 12/12 正确，无多报/漏报；`DUR_MS` 误差 ≤ ±20 ms |
| D-13 | 同一音持续 2000 ms | 仍只报 1 次（`DTMF_CFG` bit1 去重使能） | 事件数 = 1 |
| D-14 | 幅度扫描 −10 / −18 / −25 dBm0（'5' 音） | 三个幅度均检出 | 全部检出且 DIGIT 正确（-25 dBm0 对应门限余量，若漏检调 `DTMF_THR`） |
| D-15 | 时长扫描 40 / 80 / 200 ms（'8' 音） | ≥ 40 ms 均检出 | `DUR_MS` 误差 ≤ ±20 ms |
| D-16 | twist 用例：低频比高频 +4 dB / −4 dB（'2' 音） | 均检出为 '2' | 不误判为其他键（twist 容限 ±6 dB，**需查 RTL 参数确认**） |
| D-17 | 非 DTMF：单音 770 Hz / 白噪声 / 语音段（男声朗读） | 无 `DTMF_EVT` | talk-off 误报 = 0（语音段 60 s 内 0 次误报为优） |
| D-18 | 两个 DTMF 按键连按（'1' 80 ms → 静音 40 ms → '2' 80 ms） | 报 2 个事件：0x01、0x02 | 次序与 DIGIT 均正确 |
| D-19 | 带噪 DTMF：'5' 音 + 白噪声 SNR = 20 dB | 检出 '5' | 检出且无误判 |
| D-20 | 采样时钟偏差：fs = 8000 × (1 ± 1%) | 仍检出正确 DIGIT | 全部检出（偏差容忍 ≥ ±1%，**需查 RTL 参数确认**） |
| D-21 | `DTMF_CFG` bit0 = 0（关闭检测） | 无任何事件 | 事件数 = 0 |
| D-22 | `DTMF_THR` 扫描 0x20/0x40/0x80（−12 dBm0 激励） | 门限内可检出，门限外不误报 | 记录实际余量曲线，写入调测报告 |

### 1.2 G.711 A-law 编解码（`g711_codec.v`）

**全码表遍历**（256 个码字全部覆盖）：

| 用例 | 激励 | 期望结果 | 通过判据 |
|---|---|---|---|
| G-01 | 遍历码字 c = 0x00..0xFF（256 个），逐个解码 | 解码值 = ITU-T G.711 A-law 标准表对应线性值 | 256/256 与标准表**逐项一致**，0 错误 |
| G-02 | 对 G-01 每个解码值再编码 | encode(decode(c)) = c（round-trip 恒等） | 256/256 恒等 |
| G-03 | 线性输入扫描：−32124..+32124（步进 1 或覆盖全部段界点 ±1） | 编码值 = 参考实现（ITU-T 定点算法） | 全部一致；重点验证 13 个段界点 ±1 处无偏差 |
| G-04 | 满幅正弦 1 kHz，幅度 0 dBm0 | 编解码后 THD+N ≤ 35 dB（A-law 固有量化噪声） | 频谱无异常杂散（量化噪声底之外） |
| G-05 | 全零/全负/全正极值：−32124、+32124、0 | 无溢出/回绕 | 编解码值稳定、饱和正确 |
| G-06 | 上/下行 16 bit 线性 ↔ 8 bit A-law 帧格式（160 样点/帧） | 与 UART 帧 `G711A[160]` 一致 | 逐帧比对，bit-exact |

### 1.3 I2S 收发（`i2s_controller.v` + Codec 行为模型 BFM）

| 用例 | 激励 | 期望结果 | 通过判据 |
|---|---|---|---|
| I-01 | Codec BFM 以固定图案（0xA5A5、0x5A5A、0x8000、0x7FFF）上行驱动 SDIN | FPGA 解析出 16 bit 数据 | 逐字一致；MSB 相对 LRCLK 翻转沿延迟 1 个 BCLK（标准 I2S） |
| I-02 | FPGA 下行固定图案（同上）经 SDOUT | BFM 接收一致 | 16 bit 有效数据左对齐于 32 bit 槽，后 16 bit 补 0 |
| I-03 | BFM 环回：SDOUT→BFM→SDIN（数字环回路径） | 上行 = 下行 | 连续 10 s（80000 帧）bit-exact，无错位 |
| I-04 | 时钟核查：MCLK 12.288 MHz / BCLK 512 kHz / LRCLK 8 kHz | 比值 1536 : 64 : 1 | 频率误差 ≤ ±50 ppm（晶振精度） |
| I-05 | LRCLK 极性：低 = 左声道 CH0，高 = 右声道 CH1 | CH0/CH1 不互换 | 以 0xA5A5/0x5A5A 分通道图案验证 |
| I-06 | 建立/保持时间扫描（±2 ns 注入抖动） | 仍正确采样 | 无误码（余量记录入报告） |
| I-07 | 16 bit → 32 bit 槽对齐异常注入（故意偏移 1 BCLK） | 可检出/报错或错位可预期 | 偏移后数据错位为**确定性**（左移 1 bit），便于上板定位 |

### 1.4 TDM 总线与交换（`tdm_switch.v`）

| 用例 | 激励 | 期望结果 | 通过判据 |
|---|---|---|---|
| T-01 | ts_frame 对齐检查：32 时隙 × 8 bit @ 256 kHz，帧率 8 kHz | TS0 = 0x7E（同步标识） | 帧结构与 INTERFACE_SPEC §4 一致 |
| T-02 | Codec/SLIC 上行数据注入 TS1（CH0）、TS2（CH1） | UART 侧收到对应通道音频 | TS1→CH0、TS2→CH1 映射正确 |
| T-03 | UART 下行 CH0/CH1 注入 | TS17/TS18 分别输出 CH0/CH1 下行 | 时隙映射正确（`SLOT_MAP0=0x12`、`SLOT_MAP1=0x13`） |
| T-04 | 改写 `SLOT_MAP0/1`（0x06/0x07）为其他时隙号 | 数据随新时隙路由 | 寄存器改写生效且数据正确 |
| T-05 | `LOOPBACK` bit2 = 1（CH0↔CH1 交叉） | CH0 下行出现在 CH1 上行，反之亦然 | 两部话机数字互打路径正确（TS1↔TS2） |
| T-06 | 时隙注入误码（翻转单 bit） | 上行帧内容可检出差异 | 无粘连/错位，逐 bit 对应 |
| T-07 | FIFO 溢出注入（突发超深） | `STATUS` bit1（FIFO_OVF）置位 | 溢出可检出，恢复后正常 |
| T-08 | 预留时隙 TS3..TS16、TS19..TS31 | 输出 0x00/静默 | 不干扰已用时隙 |

### 1.5 UART 桥（`uart_bridge.v` + 帧协议）

| 用例 | 激励 | 期望结果 | 通过判据 |
|---|---|---|---|
| U-01 | 帧回环：PC→FPGA `AUDIO_DL(0x11)` CH0 160 B | `AUDIO_UL(0x10)` 同 CH 同载荷（`LOOPBACK` bit0=1） | 载荷 160 B bit-exact，SEQ 连续 |
| U-02 | CRC 错误注入：翻转载荷任一 bit | 该帧被丢弃 | `STATUS` bit0（UART_RX_ERR）递增；下一好帧仍正确 |
| U-03 | LEN 越界：LEN = 513、LEN = 0xFFFF | 帧丢弃，重新同步 | 无死机，错误计数增加 |
| U-04 | LEN = 0 与 LEN = 512 边界 | 正常收发 | 边界值正确处理 |
| U-05 | 失步注入：插入随机字节 + 伪 `AA 55` | 逐字节搜索重同步 | ≤ 3 字节后恢复同步（含伪头的坏帧被 CRC 拒绝） |
| U-06 | SEQ 回绕：发送 256+ 帧 | SEQ 0..255 循环 | 丢帧检测（SEQ 跳变）逻辑正确 |
| U-07 | 背靠背 `AUDIO_DL` 连发 1000 帧（无帧间空闲） | 全部接收 | 0 丢帧，FIFO 不溢出（921600 baud 余量核算见 SPEC §1） |
| U-08 | 20 ms 节拍流量：每 20 ms 一帧 × 2 通道 × 10 min | `AUDIO_UL` 稳定输出 | 0 丢帧，SEQ 连续，帧间隔抖动 ≤ ±2 ms |
| U-09 | `REG_RD/REG_WR/REG_VAL`（0x30/0x31/0x32） | 读写正确返回 `REG_VAL` | 与 §1.6 寄存器表一致 |
| U-10 | `PING(0x7E)`/`PONG(0x7F)` | 立即回 `PONG` | 往返延迟 ≤ 5 ms |
| U-11 | 波特率边界：921600（主）与 115200（调参） | 均可通 | 无误码（连续 10⁶ 字节） |

|---|---|---|---|

## 2. 上位机音频链路环回测试

目的：验证「UART 协议 ↔ FPGA ↔ I2S/Codec ↔ 模拟电话口」各段。逐级放行，前级不过不进后级。

### 2.1 级 1：UART 音频环回（`REG 0x02` bit0）

- **配置**：`REG_WR(0x02, 0x01)`（bit0=1，DL→UL 直通）；`CHAN_EN=0x03`。
- **步骤**：
  1. 上位机按 20 ms 节拍发 `AUDIO_DL(0x11)`，CH0 载荷为已知序列（帧号递增图案 + 语音样本）；
  2. 采集 `AUDIO_UL(0x10)`，逐帧与下行比对；
  3. CH1 重复；再测 `LOOPBACK` bit2=1（0x05）验证 CH0↔CH1 交叉。
- **通过判据**：
  - 连续 10 min：0 丢帧（SEQ 连续），载荷 **bit-exact**；
  - 环回延迟 ≤ 2 帧（40 ms）；
  - 错误注入（1% 随机坏帧）后链路自恢复，错误计数可读（`STATUS` bit0）。

### 2.2 级 2：I2S 数字环回（`REG 0x02` bit1）

- **配置**：`REG_WR(0x02, 0x02)`（bit1=1，I2S 数字环回：下行送 I2S 后直回上行）。
- **步骤**：
  1. 下行发送扫频语音（300–3400 Hz）与固定图案；
  2. 上行采集比对；
  3. 用示波器同时观测 TP1–TP5（MCLK/BCLK/LRCLK/SDIN/SDOUT），核对 16 bit 左对齐、1 BCLK 延迟。
- **通过判据**：
  - 载荷 bit-exact（16 bit 线性 PCM 无损）；
  - 时钟比 1536:64:1，LRCLK = 8 kHz ± 50 ppm；
  - 图案在 SDIN/SDOUT 上可辨认、无错位（对照 §1.3 I-07 的确定性错位特征排除）。

### 2.3 级 3：Codec 模拟环回（线路仿真器/免提口）

- **配置**：`REG_WR(0x02, 0x00)`（关闭数字环回），Codec 内部模拟环回或线路仿真器 2 线环回。
- **步骤**：下行 1 kHz/0 dBm0 正弦 → 测量 Codec 输出端 → ADC 回采 → 上行频谱。
- **通过判据**：电平 0 dBm0 ± 1 dB；THD+N ≤ 35 dB（A-law 量化主导）；无镜像/混叠杂散。

### 2.4 级 4：全链路模拟电话 ↔ AI 管道

- **配置**：FPGA ↔ 音频桥服务（SIP 1001）↔ Asterisk ↔ `AGI(agi_ai_route.py)` ↔ AI 管道（回声/测试机器人）。
- **步骤**：
  1. 电话 1 摘机 → 拨 `00` → 应答，AI 管道播放测试提示音；
  2. 电话端说话（测试句/单音）→ AI 管道录音 → 回放比对；
  3. 拨号 `01`+短号 → 2001 振铃、接听、双向通话；
  4. 拨 `02`+外线 → 中继出局（测试号码）；
  5. 振铃：外部呼叫 1001 → `RING_CMD` → 电话振铃 → 摘机应答。
- **通过判据**：
  - 全链路 G.711 A-law（RTP payload type = 8，无转码）；
  - 端到端单向延迟 ≤ 150 ms（含 20 ms 帧 + RTP + AGI 放音调度）；
  - 通话 10 min 无断续、无单通；DTMF 事件（拨号/交互）在 AI 管道侧全部正确；
  - 挂机事件（`HOOK_EVT`）→ SIP BYE 正确，无僵尸会话。

## 3. DTMF 误判排查（漏检/误报）

### 3.1 排查决策表

| # | 现象 | 可能原因 | 检查方法 | 判定阈值/预期 | 处置 |
|---|---|---|---|---|---|
| 1 | 漏检（按键无事件） | 能量门限 `DTMF_THR` 过高 | 读 0x03；-12 dBm0 激励下逐步降门限 | 默认 0x40；-25 dBm0 应仍可检 | 降门限至满足灵敏度 −25 dBm0 |
| 2 | 漏检 | 输入幅度过低（线路衰减/长线） | TP 测 SLIC/Codec 输入电平 | ≥ −25 dBm0 | 调 SLIC 增益/线路补偿 |
| 3 | 漏检 | twist 过大（高低频不平衡） | 分别测高/低频单音幅度 | twist ≤ ±6 dB（**需查 RTL 参数确认**） | 调 SLIC 频响；必要时放宽 twist 判据 |
| 4 | 漏检 | 采样时钟偏差 | 测 LRCLK 实频（TP3） | 8 kHz ± 50 ppm（晶振）；检测容忍 ±1% | 换晶振/改 PLL；放宽 Goertzel 带宽 |
| 5 | 漏检 | 时长过短（<40 ms） | 示波器测按键波形 | 有效时长 ≥ 40 ms | 与话机/上级交换机协商按键时长 |
| 6 | 误报（talk-off） | 门限过低 | 语音段（60 s 男/女声）回放 | 60 s 内误报 = 0 | 提高 `DTMF_THR`；确认 `DTMF_CFG` bit1 去重使能 |
| 7 | 误报 | 增益过载削顶产生互调 | 测 ADC 输入峰值 | 峰值 ≤ −3 dBm0（标称 −10 dBm0） | 降 SLIC/Codec PGA 增益 |
| 8 | 误报/串音 | 通道间串扰 | CH0 送 DTMF，CH1 静默监听 | 串扰衰减 ≥ 55 dB（**需查数据手册确认**） | 分割 AGND/地回流；检查布线 3W |
| 9 | DIGIT 错误 | 谐波失真（二次谐波落入邻带） | 频谱分析送入信号 | 谐波 ≤ −40 dBc | 修 SLIC 线性度/降低电平 |
| 10 | DIGIT 错误 | 滤波器频偏（fs 实际偏差） | 与用例 D-20 对照 | ±1% 内不错判 | 校 PLL 分频参数 |
| 11 | 事件多报 | 去抖/去重未启用 | 读 `DTMF_CFG` | bit1 = 1 | 置 `DTMF_CFG=0x03` |
| 12 | 事件通道错位 | 通道映射/时隙错 | 看 `DTMF_EVT` 的 CH 字段 | CH 与物理口一致 | 核对 `SLOT_MAP`、TDM 交换 |

## 5. 回归测试与验收标准

### 5.1 回归清单（每次改版必跑）

| 级别 | 内容 | 工时估算 |
|---|---|---|
| L1 仿真 | §1 全部用例（DTMF 22 项、G.711 6 项、I2S 7 项、TDM 8 项、UART 11 项、顶层 8 项） | 2 h（自动化） |
| L2 数字环回 | §2.1 / §2.2 | 1 h |
| L3 模拟环回 | §2.3 / §2.4（含 Asterisk 三路由 00/01/02） | 2 h |
| L4 电气 | §4 的 E-01 ~ E-09、E-16（安规项抽样或 100%） | 2 h |

### 5.2 放行判据（验收）

1. L1 仿真 0 失败；
2. 数字环回 10 min **0 丢帧、bit-exact**；
3. 全链路通话：延迟 ≤ 150 ms、10 min 无断续、DTMF/挂机事件全对；
4. 电气项全部在期望值/判据内，耐压 1500 VAC/1 min 通过；
5. DTMF：12 音 100% 正确 + 60 s 语音 0 误报。

### 5.3 测试记录模板

| 字段 | 内容 |
|---|---|
| 版本 | RTL 版本（`VERSION` 寄存器 = 0x10）、PCB 版本、配置文件版本 |
| 环境 | 仪器型号/编号、仿真线规格、温度 |
| 用例 | 编号（D-xx / G-xx / I-xx / T-xx / U-xx / TOP-xx / E-xx） |
| 结果 | PASS / FAIL / BLOCKED + 实测数值 |
| 参数变更 | `DTMF_THR`、增益、门限等调整记录 |
| 结论 | 放行/不放行，遗留问题列表 |

## 6. 已知边界与遗留确认项

| 项 | 说明 | 归属 |
|---|---|---|

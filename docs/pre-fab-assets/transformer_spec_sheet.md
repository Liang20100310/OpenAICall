# 反激变压器定制需求书（模板 v1.0）—— 发给磁件厂填写/评审

> 项目：FPGA 电话中继 + AI 语音指挥系统 ｜ 关联：`PRE_FAB_CHECKLIST.md` P0-2
> 【】为待填/待核项；"示例值"仅供首轮询价参考，最终以 Si32175/176 数据手册
> `DC-DC Converter` 章节的设计方程核算后定案。

## 1. 应用背景

- 控制器：Si32176-B-FM1 内置 tracking DC-DC 控制器，外置反激变压器产生 VBAT = -75 V；
- 输出跟踪范围：-45 V ~ -75 V（轻载自动降压跟踪，芯片特性）；
- 负载：环路馈电 20–60 mA 持续 + 振铃峰值（90 Vrms/20 Hz）短时高功率。

## 2. 电气参数（核心，需双方签核）

| 参数 | 要求 | 示例值 | 备注 |
|---|---|---|---|
| 输入电压 Vin | 5 V ±5% | 5 V | 来自系统 5 V 电源 |
| 输出电压 Vout | -75 V（跟踪 -45~-75 V） | -75 V | |
| 输出功率 Po | ≥ 5 W | 5 W | 含振铃峰值裕量 |
| 开关频率 fsw | 【按 Si3217x 手册】 | 150 kHz | 由控制器定，非自由参数 |
| 工作模式 | DCM（边界导通） | DCM | |
| 匝比 Np:Ns | 由 fsw/Dmax 核算 | 10 T : 190 T | Dmax ≤ 0.45，含二极管压降 0.5 V；允许 ±1 T 微调 |
| 辅助绕组 | 【如需反馈：5 V，X T】 | 无/5 V | 按控制器反馈方式定 |
| 初级电感 Lm | 5–10 µH，±25% | 8.2 µH | Lm ≈ Vin²·D²/(2·Po·fsw) |
| 饱和电流 Isat | ≥ 5.5 A（硬饱和拐点） | 5.5 A | ≥ 1.25 × Ipk，Ipk = 2Po/(Vin·D) ≈ 4.4 A |
| 漏感 Lk | ≤ 3% Lm | ≤ 0.25 µH | 决定 RCD 吸收 |
| DCR 初级 | ≤ 15 mΩ | ≤ 15 mΩ | 温升 ≤ 40 K 核算 |
| DCR 次级 | ≤ 3 Ω | ≤ 3 Ω | 同上 |
| 分布电容 | ≤ 20 pF | ≤ 20 pF | EMI |

## 3. 磁芯与结构

- 磁芯：EE16 / EE19 或 PQ20，PC95/PC40 功率铁氧体，气隙长度由 Lm 反推（【厂方计算后回填】）；
- 绕法：初次级三明治（降漏感），引出为骨架引脚直焊；
- 引脚定义与同名端：【附结构图，标注引脚编号】；
- 外形高度 ≤ 【X mm】（受整机结构限制）。

## 4. 绝缘与安规（关键，需提供测试报告）

| 项目 | 要求 |
|---|---|
| 初级—次级耐压 | **1500 VAC / 60 s**，漏电流 ≤ 5 mA，100% 全检 |
| 绝缘等级 | 加强绝缘，爬电 ≥ 6.4 mm（挡墙/margin 满足） |
| 绝缘材料 | 骨架/胶带 UL94 V-0；三层绝缘线或 ≥2 层 0.08 mm 绝缘胶带 + 挡墙 |
| 绝缘系统 | Class B（130 ℃）及以上 |
| 认证 | 【UL/IEC 62368-1 认证材料体系，或提供绝缘系统认证号】 |
